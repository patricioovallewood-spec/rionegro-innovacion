# Rionegro · Ciudad del Bienestar

Propuesta de Hub de Innovación para Rionegro, Antioquia, presentada por Patricio Ovalle Wood.

## Publicar en GitHub Pages

1. Crea un repositorio público llamado `rionegro-innovacion` en tu cuenta de GitHub.
2. Descomprime este ZIP en tu computador.
3. En el repositorio, elige **Add file → Upload files**. Sube todos los archivos descomprimidos directamente a la raíz del repositorio; `index.html` debe quedar allí, fuera de cualquier carpeta adicional. No subas el ZIP sin descomprimir.
4. Confirma la carga con **Commit changes**.
5. Ve a **Settings → Pages**.
6. En **Build and deployment → Source**, selecciona **Deploy from a branch**.
7. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
8. Cuando termine la publicación, GitHub mostrará la dirección del sitio en esa misma sección.

## Contenido

- `index.html`: propuesta integral y orientador interactivo.
- `lab.html`: innovación pública y mejora de servicios.
- `sandbox.html`: GovTech, experimentación y sandboxes.
- `hub.html`: emprendimiento y desarrollo del ecosistema.
- `invest.html`: inversión, investigación e I+D+i.
- `rionegro-institucional.css`: identidad visual compartida.
- `logo-rionegro.png`: logo institucional.
- `.nojekyll`: permite servir los archivos directamente.

El sitio es estático: no necesita instalar dependencias ni ejecutar una compilación. Conserva los nombres de archivo para mantener todos los enlaces internos. Las fuentes tipográficas se cargan desde Google Fonts y requieren conexión; si no están disponibles, se utilizan fuentes del sistema.

## Alcance de la propuesta

Las cinco páginas incorporan el concepto «Rionegro, Ciudad del Bienestar», con una paleta inspirada en el Plan de Desarrollo 2024–2027. Programas, cifras y casos ilustrativos son parte de una propuesta y están sujetos a validación municipal; este sitio no constituye un portal oficial de la Alcaldía.
